# 🏰 AgentTavern

> Una interfaz de gestión de agentes IA con estética de taberna medieval pixel art. Inspirado en AgentCraft pero con nuestra propia personalidad.

## 🌟 La Idea

AgentTavern es un proyecto para gestionar agentes OpenCode desde una interfaz visual estilo "taverna medieval pixelada" — donde los agentes son personajes sentados en mesas, las tareas son quests, y el mapa representa la estructura del proyecto.

## 🎮 Estética

- **2D Pixel Art** estilo Gameboy/Pokémon (sin 3D, sin complejidad innecesaria)
- **La Taberna**: Mesas donde los agentes trabajan, jarras como indicadores de estado
- **Mapa = Estructura del proyecto**: Las "zonas" representan directorios

## 🛠️ Tech Stack

- **Frontend**: React + Tailwind CSS + Canvas (para el mundo de la taberna)
- **Backend**: Go (aprendiendo!)
- **Agentes**: OpenCode
